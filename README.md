# Banking Database System

A university database project focused on designing and implementing a relational database for a banking information system using Oracle SQL and PL/SQL.

## Technologies
- Oracle Database
- SQL and PL/SQL
- Oracle Data Modeler

## Project Features
- Relational database design for banking operations
- Management of customers, bank accounts, employees and transactions
- SQL queries using JOIN, GROUP BY and aggregate functions
- PL/SQL procedures, triggers, cursors and sequences

## Documentation
The repository contains the university project documentation, including database design and SQL/PLSQL examples.

## Project Type
University coursework – Database Systems.
